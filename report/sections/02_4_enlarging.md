## 2.4 Enlarging by seam insertion

Avidan and Shamir enlarge an image by reversing seam removal: instead of deleting low-energy seams, new pixels are inserted along them (§4.3). The obvious way to add one column is to find the optimal vertical seam and duplicate it. Repeating this step does not work: the duplicated pixels are averages of their neighbours, so they form a smooth, low-energy region and the next search picks the same seam (or its neighbour) again. The paper shows that this "repeat the best seam" approach stretches a single strip of the image (Fig. 8b). We implement this naive version only in the D4 script, to reproduce that failure.

The method of the paper finds the first k seams that would be removed when shrinking the image by k columns and duplicates all of them at once. This can be read as going back in time: the inserted pixels are those a larger image would have lost during seam removal. Our implementation reuses shrinking: `carve.shrink_width(img, k)` returns a `ShrinkResult` whose `removed` field is a boolean (H, W) map in original coordinates with exactly k `True` values per row, i.e. the k seams already mapped back through the index map. `insert_vertical_seams(img, removed)` then builds the (H, W + k) output with `np.repeat`, writing every chosen pixel twice, and replaces each copy by the mean of the chosen pixel and its right neighbour (the left neighbour in the last column). Original pixels keep their values and order; `inserted_mask` gives the positions of the new pixels, so removing them restores the input exactly. The paper describes the new pixels as averages with the left and right neighbours; we use the one-sided mean fixed in our interface, which never modifies an original pixel.

Inserting many seams in one pass approaches plain scaling, since duplicating every seam is equivalent to scaling. To stay content-aware for large enlargements (above 50%), the paper splits the process into several steps (§4.3). `enlarge_width` inserts at most `floor(max_step × current width)` seams per step (default `max_step = 0.5`), never more than the current width minus one, and recomputes the seams on the enlarged image before the next step.

Content amplification (§4.4) keeps the image size but enlarges its content: the image is first scaled up by a factor (`cv2.resize`, bicubic), then seam carving removes columns and rows until the original size is reached (`amplify_content`).
