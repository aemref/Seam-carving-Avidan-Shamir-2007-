Mirza implemented seam removal in `seamcarving/carve.py`: the shrinking loop that recomputes the energy after every seam, removes it with a boolean mask, carries side arrays such as protection masks along with the image, and keeps an index map so that every removed pixel is recorded with the step that removed it; `shrink_height` reuses the same code on the transposed image. Mirza also wrote the baselines in `seamcarving/baselines.py` (scaling, centre crop, best crop with an integral image, column removal and per-row pixel removal) and the end-to-end tests in `tests/test_integration.py`, which run the real energy, seam, shrinking and enlarging code together. Mirza contributed four photos with their masks, ran experiments D2 (seam carving against scaling and cropping) and D3 (energy preservation, paper Fig. 3), and wrote report sections 2.3 (shrinking) and 6.2 (shrinking results).
